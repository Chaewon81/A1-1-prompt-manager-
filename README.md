# Prompt Manager

Python으로 만든 개인 프롬프트 관리 프로그램입니다.

프롬프트를 카테고리별로 관리하고, 키워드로 검색하거나
자주 사용하는 프롬프트를 즐겨찾기로 관리할 수 있는
콘솔 기반 프로그램입니다.

## 실행 방법

Python 3.10 이상이 설치된 환경에서 다음 명령어를 실행합니다.

```bash
python prompt_manager.py


주요 기능
  • 프롬프트 추가
  • 프롬프트 목록 보기
  • 카테고리별 조회
  • 프롬프트 검색
  • 프롬프트 상세 보기
  • 즐겨찾기 추가/해제
  • 즐겨찾기 목록 보기

프롬프트 카테고리
  • 텍스트 생성
  • 이미지 생성
  • 영상 생성
  • 페르소나
  • 자동화
  • 기타

기본 제공 프롬프트
  1. 영어회화 선생님
  2. 축구 포스터 생성
  3. AI 학습 코치

개발 환경
  • Python 3.14
  • Visual Studio Code
