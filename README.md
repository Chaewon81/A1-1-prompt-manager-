## ✨ 주요 기능

### 1. 프롬프트 추가

새로운 프롬프트의 제목, 내용, 카테고리를 입력하여 추가할 수 있습니다.

기본 카테고리:

* 텍스트 생성
* 이미지 생성
* 영상 생성
* 페르소나
* 자동화
* 기타

기존 카테고리 외에도 사용자가 직접 새로운 카테고리를 입력할 수 있습니다.

예:

```text
새 카테고리를 입력하세요: 공부
새 카테고리 '공부'가 추가되었습니다.
프롬프트가 추가되었습니다.
```

---

### 2. 프롬프트 목록 보기

현재 등록된 모든 프롬프트를 번호, 즐겨찾기 상태,
제목, 카테고리와 함께 확인할 수 있습니다.

예:

```text
===== 프롬프트 목록 =====
1 ☆ 영어회화 선생님 [ 텍스트 생성 ]
2 ☆ 축구 포스터 생성 [ 이미지 생성 ]
3 ☆ AI 학습 코치 [ 페르소나 ]
4 ☆ 테스트 프롬프트 [ 공부 ]
```

---

### 3. 카테고리별 조회

원하는 카테고리를 선택하면 해당 카테고리에 등록된
프롬프트만 확인할 수 있습니다.

예:

```text
===== 카테고리별 조회 =====
1 텍스트 생성
2 이미지 생성
3 영상 생성
4 페르소나
5 자동화
6 기타
7 공부
```

---

### 4. 프롬프트 검색

키워드를 입력하면 프롬프트의 제목과 내용을 대상으로
부분 문자열 검색을 수행합니다.

예:

```text
검색할 키워드를 입력하세요: 영어

1 ☆ 영어회화 선생님 [ 텍스트 생성 ]
```

현재 검색 방식은 Python의 `in` 연산자를 이용한
선형 탐색 방식입니다.

프롬프트를 처음부터 하나씩 확인하므로 데이터가 많아질 경우
검색 시간이 증가할 수 있습니다.

현재 데이터 규모에서는 단순하고 이해하기 쉬운 방식이라는 장점이 있습니다.

---

### 5. 프롬프트 상세 보기

프롬프트 번호를 입력하면 제목, 카테고리, 즐겨찾기 상태,
프롬프트 내용을 상세하게 확인할 수 있습니다.

예:

```text
===== 프롬프트 상세 보기 =====
프롬프트 번호를 입력하세요: 1

제목: 영어회화 선생님
카테고리: 텍스트 생성
즐겨찾기: ☆
내용: 너는 영어회화 전문 선생님이야.
```

---

### 6. 즐겨찾기 관리

자주 사용하는 프롬프트를 즐겨찾기에 추가하거나 해제할 수 있습니다.

제공 기능:

* 즐겨찾기 추가/해제
* 즐겨찾기 목록 보기

예:

```text
⭐ 즐겨찾기에 추가되었습니다.

===== 즐겨찾기 목록 =====
4 ⭐ 테스트 프롬프트 [ 공부 ]
```

## 🏗️ 함수 설계

프로그램은 각 기능을 함수 단위로 분리하여 관리합니다.

| 함수                   | 역할                  |
| -------------------- | ------------------- |
| `show_menu()`        | 메인 메뉴 출력            |
| `add_prompt()`       | 새로운 프롬프트 추가         |
| `show_prompts()`     | 전체 프롬프트 목록 출력       |

각 함수는 하나의 주요 책임을 담당하도록 구성했습니다.

메인 프로그램에서는 사용자의 메뉴 선택에 따라 해당 함수를 호출합니다.

## 🗃️ 데이터 구조

프롬프트 데이터는 Python의 `list`와 `dictionary`를 조합하여 관리합니다.

각 프롬프트는 다음과 같은 구조를 사용합니다.

```python
{
    "title": "영어회화 선생님",
    "content": "너는 영어회화 전문 선생님이야.",
    "category": "텍스트 생성",
    "favorite": False
}
```

### 필드 설명

| 필드         | 타입     | 설명         |
| ---------- | ------ | ---------- |
| `title`    | `str`  | 프롬프트 제목    |
| `content`  | `str`  | 실제 프롬프트 내용 |
| `category` | `str`  | 프롬프트 카테고리  |
| `favorite` | `bool` | 즐겨찾기 여부    |

---

## 🤔 List와 Dictionary를 선택한 이유

프롬프트 하나는 제목, 내용, 카테고리, 즐겨찾기 상태 등
여러 속성을 가지고 있기 때문에 각 속성을 이름으로 관리할 수 있는
Dictionary가 적합하다고 판단했습니다.

여러 개의 프롬프트를 순서대로 관리하기 위해 Dictionary를 List에 저장하는 구조를 사용했습니다.

### 장점

* Python 기본 자료구조만으로 구현 가능
* 코드가 단순하고 이해하기 쉬움
* 필드 이름을 통해 데이터를 명확하게 접근할 수 있음
* 소규모 데이터 관리에 적합

### 단점

* 데이터가 많아지면 검색 성능이 떨어질 수 있음
* 프로그램 종료 후 데이터가 유지되지 않음
* 데이터 중복이나 고유 ID 관리가 제한적임

## 🔍 검색 알고리즘

검색 기능은 제목과 내용에 키워드가 포함되어 있는지를 확인하는
부분 문자열 검색 방식을 사용합니다.

개념적으로 다음과 같은 방식입니다.

```python
if keyword in prompt["title"] or keyword in prompt["content"]:
    ...
```

현재는 프롬프트 전체를 순차적으로 확인합니다.

프롬프트가 `n`개라면 검색의 시간 복잡도는 기본적으로 `O(n)`입니다.

현재와 같은 소규모 데이터에서는 구현이 간단하고 충분한 성능을 제공합니다.

향후 데이터가 많아질 경우 데이터베이스나 검색 인덱스 등을
사용하여 검색 성능을 개선할 수 있습니다.

## 🛡️ 입력값 검증

사용자의 잘못된 입력으로 프로그램이 중단되지 않도록
메뉴 번호와 프롬프트 번호 등의 입력값을 검증합니다.

예:

```text
카테고리 번호를 입력하세요: 0
잘못된 번호입니다.
```

또한 제목이나 내용처럼 반드시 입력되어야 하는 값은
빈 문자열이 입력되지 않도록 검증합니다.

입력값 검증을 통해 프로그램의 안정성과 사용자 경험을 높였습니다.

## 🔁 메인 반복문 설계

프로그램은 `while` 반복문을 이용하여 사용자가 원하는 기능을
여러 번 사용할 수 있도록 설계했습니다.

메인 메뉴에서 사용자가 선택한 기능을 실행한 뒤 다시 메뉴를 표시합니다.

종료 조건은 사용자가 `0`을 입력하는 것입니다.

```text
메뉴 출력
   ↓
사용자 입력
   ↓
기능 실행
   ↓
다시 메뉴 출력
   ↓
0 입력 시 종료
```

이러한 구조를 사용하면 프로그램을 종료하지 않고 여러 기능을
연속적으로 사용할 수 있습니다.

## 💾 데이터 영속화 설계

현재 프로그램의 프롬프트 데이터는 Python 프로그램 실행 중
메모리에서 관리됩니다.

따라서 프로그램을 종료하면 사용자가 추가한 프롬프트와
즐겨찾기 상태가 유지되지 않습니다.

향후 영속화 기능을 추가할 경우 **JSON 파일 방식**을 우선 고려합니다.

### JSON을 선택하는 이유

* Python의 Dictionary/List 구조와 자연스럽게 연결할 수 있음
* 별도의 데이터베이스 설치가 필요 없음
* 사람이 직접 파일 내용을 확인할 수 있음
* 소규모 개인용 프로그램에 적합

예상 구조:

```text
prompt_manager.py
prompts.json
```

향후 다음 기능을 추가할 수 있습니다.

```text
프로그램 시작
    ↓
prompts.json 불러오기
    ↓
프롬프트 관리
    ↓
프롬프트 추가/즐겨찾기 변경
    ↓
prompts.json 저장
```

## 🔐 중복 및 충돌 처리 정책

현재 프로그램은 프롬프트 제목의 중복을 허용합니다.

예를 들어 다음과 같은 프롬프트를 여러 개 등록할 수 있습니다.

```text
영어회화 선생님
영어회화 선생님
```

제목만으로 프롬프트를 식별하면 충돌 가능성이 있으므로,
향후 데이터 영속화를 구현할 경우 각 프롬프트에 고유 ID를 부여하는
방식을 고려합니다.

예:

```text
1 - 영어회화 선생님
2 - 영어회화 선생님
```

카테고리는 기존 카테고리를 선택하거나 사용자가 직접 새로운 카테고리를
입력할 수 있도록 설계했습니다.

새로운 카테고리는 기존 카테고리 목록에 추가됩니다.
